# Salut, moi c'est James !👋 

### Étudiant en Développement Web & Passionné de Tech 🚀

Actuellement en **Bachelor Développement Web** à Digital Campus Paris, je combine une solide base technique avec une expérience de terrain en gestion d'équipe.Je suis à la recherche d'opportunités pour mettre mes compétences au service de projets innovants tout en poursuivant mes études.
